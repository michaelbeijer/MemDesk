One-time Google setup

The extension talks to Gmail from this browser with your own Google Cloud project - free, and about ten minutes, once. Nothing is sent anywhere else. The full guide, with pictures of each screen, is SETUP.md.

  1. Create a project at console.cloud.google.com, then turn on the Gmail API in it.
  2. Set up the consent screen: audience Internal on a Google Workspace account; on an @gmail.com account, External, and then Publish app (no review is needed for yourself, and it stops Google asking you to sign in again every week).
  3. In Credentials, choose Create credentials → OAuth client ID, application type Web application, and under Authorised redirect URIs add the redirect URI above, exactly as shown.
  4. Create it, then paste the Client ID below. No client secret is needed.

OAuth client

The test opens Google's sign-in so you can pick an account, then reads that mailbox's address back from Gmail. It sends nothing and changes nothing.

Privacy

There is no server. The access token lives only in this browser's session storage and is gone when Chrome closes. Card order is kept in this browser; your column layout and your own card titles, notes and colours sync through your Chrome profile and are never written to your mail. Notes are messages in your own mailbox under “_Notes”, never sent. The extension never sends mail, never permanently deletes anything, and only ever moves its own notes to Trash.
